# 困扰人类上百年、至今仍未解决的数学难题

> 收录标准：**问题提出已满 100 年（或源头可追溯到 19 世纪及更早），且截至今天仍无公认的完整解答**。
> 文末附「已经攻克的百年老题」作为对照，避免把已解决的经典问题误当成未解难题。

---

## 一、数论：老题最密集的地区

数论是“百年悬案”的重灾区，因为它的命题往往一句话就能说清，却牵动着素数分布的深层结构。

### 1. 黎曼猜想（Riemann Hypothesis, 1859）
ζ 函数的所有非平凡零点都位于直线 Re(s) = 1/2 上。
- 年龄：160 余年。
- 意义：素数分布误差项的“总开关”。成立则素数定理的误差可大幅收紧，并对上千条数论命题“一键成立”。
- 现状：已验证前 10^13 个零点；有限域上的类比（Weil 猜想）已于 1974 年由 Deligne 证明。Clay 千禧七题之一，悬赏 100 万美元。

### 2. 哥德巴赫猜想（1742）
每个大于 2 的偶数都是两个素数之和（强猜想，即“1+1”）。
- 年龄：280 余年。
- 进展：陈景润 1973 年证明“1+2”（一个素数 + 一个至多两个素因子之积）；**弱猜想**（每个大于 5 的奇数都是三个素数之和）已由 Helfgott 于 2013 年完整证明。
- 现状：强猜想仍未解决。

### 3. 孪生素数猜想（de Polignac, 1849）
存在无穷多对相差 2 的素数。
- 进展：张益唐 2013 年证明存在无穷多对间隔有界的素数（最初界为 7000 万），经 Polymath8 协作改进到 246。
- 现状：从“有界间隔”到“间隔恰为 2”，仍是天堑。

### 4. 奇完全数与完全数的无穷性（欧几里得—欧拉，2000 余年）
- 是否存在**奇完全数**？至今一个也没找到，且已证明若存在必大于 10^1500，且至少有 101 个素因子（不同结果略有差异）。
- 是否存在**无穷多个完全数**（已知的全是偶数，形如 2^(p−1)(2^p−1)）？未知。
- 这是本清单里“年龄最大”的一类问题。

### 5. 欧拉—马斯刻若尼常数 γ 的无理性（1735）
γ = lim_{n→∞}(1 + 1/2 + … + 1/n − ln n) ≈ 0.5772156649…
- 无人能证明它是有理数还是无理数，更谈不上超越性。已算出上万亿位，仍无定论。

### 6. 是否存在无穷多个费马素数（费马, 1640）
形如 2^(2^n) + 1 的素数。目前只在 n = 0,1,2,3,4 时成立，n ≥ 5 中已检验者全部为合数（目前未发现新的费马素数），但“只有有限个”也未被证明。

### 7. 是否存在无穷多个梅森素数（17 世纪起）
形如 2^p − 1 的素数。已知 50 余个（GIMPS 分布式搜索仍在推进），但无穷性未证。

### 8. 兰道四问题（Landau, 1912）
一次会议上提出的四个“素数基本问题”，至今全部未解：
1. 哥德巴赫猜想；
2. 孪生素数猜想；
3. 相邻平方数之间是否总有素数（Legendre 猜想）；
4. 是否存在无穷多个形如 n² + 1 的素数。

### 9. 圆周率 π 的正规性、以及 π + e 的无理性
- π 的十进制展开是否“均匀包含所有数字串”（正规数）——未知，尽管已算出上百万亿位。
- π + e、π·e 是否无理、是否超越——未知（π 和 e 各自超越性早已由 Lindemann、Hermite 证明）。
- ζ(3) 的无理性由 Apéry 于 1978 年证明，但 ζ(5)、ζ(7) 等的无理性仍未知。

### 10. 逆伽罗瓦问题（19 世纪末，Hilbert 时期）
是否每个有限群都能作为有理数域 Q 的某个伽罗瓦扩张的伽罗瓦群实现？答案对可解群已知为是，一般情形未知。

### 11. 一批 19 世纪—20 世纪初的经典猜想
- **布罗卡问题**（1876）：n! + 1 = m² 是否只有 4!+1=5²、5!+1=11²、7!+1=71² 三组解？
- **阿廷原根猜想**（1927）：给定非平方整数 a，是否存在无穷多素数 p 使 a 是模 p 的原根（且有正密度）。
- **巴尼亚科夫斯基猜想**（1857）：整系数不可约多项式若对所有整数取值无固定公因子，则取素数值无穷多次。
- **Dickson 猜想**（1904）、**Schinzel 假设 H**（1958）：素数 k 元组猜想的统一形式，涵盖孪生素数、哥德巴赫等大量特例。

## 二、分析与偏微分方程

### 12. 纳维—斯托克斯方程解的存在性与光滑性（Clay 千禧题，问题源头为 19 世纪）
三维不可压缩 NS 方程：任意光滑初值下，是否整体存在光滑解？还是会有限时间爆破？
- 这是“流体力学的基本语法”，也是唯一一个“工程师天天在算、数学家却不知道解是否存在”的方程。
- 二维情形已解决（整体光滑解存在），三维卡住。

### 13. 欧拉方程、玻尔兹曼方程、可压缩 NS 的适定性
同类问题：解的全局正则性、爆破准则、奇异极限（流体动力学极限）等，多数在三维情形开放。

### 14. n 体问题的稳定性（n ≥ 4）
- 三体问题的一般解结构由 Poincaré 开创，但“限制性三体”的许多定性问题仍开放。
- n ≥ 4 时，周期解的分类、稳定性、碰撞—逃逸结构远未完成。

## 三、几何与拓扑

### 15. 希尔伯特第 16 问题（后半，1900）
平面多项式向量场的极限环个数是否有统一上界？即便二次系统（n = 2）的极限环最大数目也仍未知（已知至少 4 个）。

### 16. 四维光滑庞加莱猜想
拓扑版本已由 Freedman（1982）解决，但**光滑**四维情形仍开放——四维是唯一一个“拓扑与光滑结构分道扬镳”的维度，也是 exotic R⁴ 存在的原因。

### 17. 高维球堆积问题（开普勒猜想的高维版）
三维开普勒猜想已由 Hales 证明（1998 年宣布，2014 年形式化验证完成），但 4 维及以上最优堆积密度仅少数维度已知（8 维、24 维由 Viazovska 等人 2016 年解决），一般高维仍开放。

### 18. 完美长方体（欧拉时代）
是否存在棱长、面对角线、体对角线全为整数的长方体？已找到“几乎完美”的例子，但完整的完美长方体一个也没有，存在性未定。

## 四、代数与代数几何

### 19. 雅可比猜想（Keller, 1939）
若多项式映射 F: C^n → C^n 的雅可比行列式为非零常数，F 是否可逆（多项式自同构）？n = 1 显然，n = 2 在特定条件下有结果，一般情形开放。

### 20. 霍奇猜想（1950，Clay 千禧题）
复代数簇上的霍奇类是否都是代数闭链的有理线性组合？它是“代数几何与拓扑之间的桥”，也是千禧题中公认最“玄”的一题。

### 21. Grothendieck 标准猜想、Bloch–Kato 猜想
motive 理论的地基性猜想，绝大多数情形开放，且与黎曼猜想、BSD 猜想深度纠缠。

## 五、计算与组合

### 22. 考拉兹猜想（3n+1 问题，1937）
任取正整数，偶数除以 2，奇数乘 3 加 1，是否最终都落到 1？已验证到约 2^68，无例外，但无人能证。

### 23. P vs NP（Cook, 1971）
- 严格来说只有 50 余年，不到“百年”，但它是计算机科学的“黎曼猜想”，且与数论难题（整数分解、离散对数）互为支撑。
- 现状：公认 P ≠ NP，但连“证明方法为何失效”都被 Baker–Gill–Solovay 的相对化障碍、Razborov–Rudich 的自然证明障碍、Aaronson–Wigderson 的代数化障碍层层封锁。

### 24. 整数分解是否有多项式时间算法
与 P vs NP、量子计算（Shor 算法）紧密相关，经典模型下未知。

## 六、对照：已经攻克的“百年老题”

这些常被误列为未解，实际上已经解决：

| 问题 | 提出 | 解决 |
|---|---|---|
| 费马大定理 | 1637 | Wiles–Taylor, 1995 |
| 四色定理 | 1852 | Appel–Haken, 1976 |
| 开普勒猜想（三维球堆积） | 1611 | Hales, 1998/2014 |
| 庞加莱猜想 | 1904 | Perelman, 2002–2003 |
| 弱哥德巴赫猜想 | 1742 | Helfgott, 2013 |
| 卡特兰猜想 | 1844 | Mihăilescu, 2002 |
| 希尔伯特第 10 问题（否定解） | 1900 | Matiyasevich, 1970 |
| 连续统假设 | 1878 | 独立性：Gödel 1940 + Cohen 1963 |
| 移动沙发问题 | 1966 | Baek, 2024（预印本，待同行评议） |

> 注意：连续统假设不是“未解决”，而是被证明在 ZFC 内**不可判定**——这与“没做出来”是两种完全不同的处境。

## 八、为什么这些问题能活过一百年？

1. **表述极简，结构极深**：一句话能说给中学生听（哥德巴赫、3n+1），却要求人类理解素数或整数轨道的全局结构。
2. **现有工具存在“天花板”**：解析数论的圆法、筛法各有硬上限（筛法无法区分 1+1 与 1+2 的奇偶性障碍）；代数几何的深层猜想又互相循环依赖。
3. **反例极难构造、正例也极难推广**：奇完全数、完美长方体都是“找不到也证不出”的典型。
4. **验证不等于证明**：计算到 10^13、10^68 只排除有限范围，数学要求的是全称命题。
